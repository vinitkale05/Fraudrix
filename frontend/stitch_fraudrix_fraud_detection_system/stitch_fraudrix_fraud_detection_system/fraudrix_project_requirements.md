# Fraudrix: AI-Powered Fraud Detection & Risk Scoring System

## Project Overview
Fraudrix is a high-performance FinTech platform designed to detect fraudulent transactions in real-time. It leverages a combination of machine learning models, custom rule engines, and streaming data analysis to provide instant risk scoring and automated alerts.

## Core Features
1. **Real-Time Fraud Detection**: Instant analysis of incoming transactions with risk scoring (0-100).
2. **ML-Based Prediction**: Advanced predictive modeling (Logistic Regression/Random Forest) integrated with a robust Java backend.
3. **Custom Rule Engine**: Flexible rule sets for identifying large transactions, unusual locations, and rapid-fire activity.
4. **Fraud Analytics Dashboard**: Comprehensive view of risk trends, fraud hotspots, and real-time alerts.
5. **Smart Alerting System**: Multi-channel notifications (Email/SMS) for high-risk flags.

## Visual Direction
